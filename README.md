# Project One

Odoo 17 custom modules.

## Modules
- app_one: real estate (properties, agents)

## Setup
1. Clone Odoo 17 Community: `git clone https://github.com/odoo/odoo.git --depth 1 --branch 17.0`
2. Copy `project_one.conf.example` to `project_one.conf` and edit paths/passwords.
3. Run: `python odoo-bin -c project_one.conf -i app_one`
